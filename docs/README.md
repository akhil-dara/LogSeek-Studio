# LogSeek Studio documentation

LogSeek Studio is a Windows desktop app for exploring very large log and table files. These pages explain how to use it. Start with Getting started, then read the other pages in any order.

| Page | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Opening a file, the **Check before opening** sheet, several files as one view, cases, workbooks, packed files and event logs, where indexes are kept, starting from scratch. |
| [The workspace](the-workspace.md) | The screen areas, the focused cell, selecting and copying, tags, colour rules, and the ways to show, order, pin, wrap, sort and group columns. |
| [Searching and filtering](searching-and-filtering.md) | The search box, filter words and operators, value lists, time filters and the time spine, quiet gaps, Build a search, saved searches, the query workspace, Find, undo and redo. |
| [Columns and formulas](columns-and-formulas.md) | Columns you make, the Add a column cards, Convert items, every formula function, and what a value that cannot be worked out looks like. |
| [Analysis](analysis.md) | Summarise, group rows, unusual rows, what sets rows apart, what is new in a period, timeline signals, patterns, shapes, strange text, rare pairs, follow related rows, list search. |
| [Export and sharing](export-and-sharing.md) | Exporting rows, copying, and tags as evidence marks. |
| [Keyboard](keyboard.md) | Every key, grouped. |
| [Limits and known gaps](limits-and-known-gaps.md) | What is not there yet. |
| [How it works](how-it-works.md) | The engine, the index and how a search is answered, with diagrams. |
| [Building it yourself](building.md) | What you need, building the program and the installer, running the tests, how releases are made. |

The project's main page is the [README](../README.md).
